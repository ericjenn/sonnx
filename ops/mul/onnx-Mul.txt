# ONNX operator definition, as the `onnx` package 1.23.1 states it (schema of opset 14)

**Mul**, since opset 14.

Performs element-wise binary multiplication (with Numpy-style broadcasting support).

This operator supports **multidirectional (i.e., Numpy-style) broadcasting**; for more details please check [the doc](Broadcasting.md).

(Opset 14 change): Extend supported types to include uint8, int8, uint16, and int16.

- type constraint `T`: `tensor(uint8)`, `tensor(uint16)`, `tensor(uint32)`, `tensor(uint64)`, `tensor(int8)`, `tensor(int16)`, `tensor(int32)`, `tensor(int64)`, `tensor(float16)`, `tensor(float)`, `tensor(double)`, `tensor(bfloat16)`. Constrain input and output types to all numeric tensors.

- Input `A` (`tensor(uint8)`, `tensor(bfloat16)`, `tensor(int64)`, `tensor(float16)`, `tensor(double)`, `tensor(uint16)`, `tensor(float)`, `tensor(int16)`, `tensor(uint32)`, `tensor(int8)`, `tensor(uint64)`, `tensor(int32)`): First operand.
- Input `B` (`tensor(uint8)`, `tensor(bfloat16)`, `tensor(int64)`, `tensor(float16)`, `tensor(double)`, `tensor(uint16)`, `tensor(float)`, `tensor(int16)`, `tensor(uint32)`, `tensor(int8)`, `tensor(uint64)`, `tensor(int32)`): Second operand.
- Output `C` (`tensor(uint8)`, `tensor(bfloat16)`, `tensor(int64)`, `tensor(float16)`, `tensor(double)`, `tensor(uint16)`, `tensor(float)`, `tensor(int16)`, `tensor(uint32)`, `tensor(int8)`, `tensor(uint64)`, `tensor(int32)`): Result, has same element type as two inputs

This operator has no attribute.

Documentation page: https://onnx.ai/onnx/operators/onnx__Mul.html
