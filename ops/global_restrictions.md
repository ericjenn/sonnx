# Global restrictions

These restrictions apply to every operator of the SONNX profile.  Every operator
specification links to this file from each of its `## Restrictions` sections, with the
sentence `[General restrictions](./global_restrictions.md) are applicable.`; the rows below
are context for an operator's semantics, and they are **not** copied into the operator's
document.

| Restriction | Statement | Origin |
| -------- | ------- | ------- |
| `[G1]` | An optional attribute for which the node gives no value has no default value | [No default values](../../../../deliverables/reqs/reqs.md#no_default_value) |
