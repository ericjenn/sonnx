# ONNX operator definition, as the `onnx` package 1.23.1 states it (schema of opset 7, the opset asked for is 14)

**Asin**, since opset 7.

Calculates the arcsine (inverse of sine) of the given input tensor, element-wise.

- type constraint `T`: `tensor(float16)`, `tensor(float)`, `tensor(double)`. Constrain input and output types to float tensors.

- Input `input` (`tensor(double)`, `tensor(float16)`, `tensor(float)`): Input tensor
- Output `output` (`tensor(double)`, `tensor(float16)`, `tensor(float)`): The arcsine of the input tensor computed element-wise

This operator has no attribute.

Documentation page: https://onnx.ai/onnx/operators/onnx__Asin.html
