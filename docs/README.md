# Documentation

The normative documents of the SONNX profile.

| file | contents |
|---|---|
| `informal_corrected.md` | the specification guidelines — the normative document every accepted `ops/<op>/<op>.md` is checked against |
| `informal_spec_template.md` | the required skeleton of a specification |
| `accuracy.md` | the accuracy guidelines an operator specification refers to for the error an implementation introduces |
| `archive/informal.md` | the earlier, uncorrected draft of the guidelines, kept for history; `informal_corrected.md` supersedes it |
| `archive/claude-session-2026-10-04.txt` | a historical session log, kept as evidence of the MaxPool run |
